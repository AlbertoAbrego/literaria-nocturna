## Input

Background:

- midnight

Border:

- graphite

Text:

- parchment

Placeholder:

- ash

Focus:

- antique-gold outline

---

## Card

Background:

- charcoal

Border:

- subtle graphite border

Padding:

- 24px

Cards should have a sense of weight and permanence.

---

## Table

Tables should resemble a curated catalog.

Header:

- serif font,
- muted gold text,
- increased letter spacing.

Rows:

- generous vertical spacing,
- subtle hover highlight,
- thin separators.

Avoid dense data-grid aesthetics.

---

## Navigation

Height:

- 64px

Background:

- midnight

Border bottom:

- subtle graphite border

Navigation should feel calm and unobtrusive.

---

## Pagination

Rounded buttons.

Muted appearance.

Current page highlighted with antique gold.

---

## Empty State

Centered content.

Book icon or archive icon.

Message should feel literary.

Example:

> “No volumes have been cataloged yet.”

---

## Error State

Use restrained red tones.

Avoid alarming warning styles.

Example:

> “The archive could not be reached.”

---

## Loading State

Skeleton components preferred over spinners.

Animations should be slow and subtle.

---

## Page Layout

Content width:

- 1200px max.

Horizontal padding:

- 24px desktop,
- 16px mobile.

Vertical spacing between sections:

- 32–48px.

---

## Design Consistency Rules

Every new component should:

- use design tokens,
- respect spacing scale,
- use the established typography,
- avoid hardcoded colors,
- support dark mode by default,
- maintain editorial simplicity.

Components should feel like they belong to the same **library archive**, not to different design systems.
